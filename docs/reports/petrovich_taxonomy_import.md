# Статус источника Петрович

Дата: 18 ноября 2026. Проверенный исходный commit `main`:
`135de82b4545dc94d247d5d339f72b647f6ba4a0`, локально совпадал с GitHub.
Реализация остаётся незакоммиченной; commit/push выполняет владелец.

**PETROVICH IMPORT: BLOCKED.** Документированного разрешения на массовое получение
и повторное использование полного дерева нет — владелец явно уточнил это в задаче.
Фиктивный документ разрешения не создавался. Прямой запрос
`https://petrovich.ru/robots.txt` 18 ноября вернул HTTP 403; дальнейший обход остановлен.
`https://petrovich.ru/catalog/` доступен для ограниченного просмотра web-инструментом,
но это не подтверждает лицензию, полноту дерева или доступность прямому HTTP-клиенту.
Документированного API полного дерева не установлено. Неизвестные ветви не объявляются полными.

Число категорий/корней/листьев/глубина Петровича, дубли/циклы/ошибки исходного дерева,
записи PostgreSQL до/после и повторный импорт Петровича **не измерены**.
Никакие синтетические счётчики не выдаются за его реальные данные.
Рабочая БД на `aistation` агентом не изменялась; доступ к серверной shell не предоставлен.

По уточнённому scope реализуется независимый механизм файлового импорта и отдельное
ручное применение утверждённого дерева. Проверки выполняются на собственных JSON/HTML
фикстурах и изолированной тестовой PostgreSQL. Товары, цены и frontend не входят в этап.

Актуальный эксплуатационный отчёт по фактической БД создаёт отдельная команда `report`
в `.tmp/reports/petrovich_taxonomy_import.md`. В нём SQL counts, уровни, корневые ветви,
ошибки, источник/лицензия, snapshot SHA, commit и журнал реальных apply.
Он не включается в Git; передайте его владельцу после отдельно утверждённого импорта.

Путь согласования: получить разрешённую выгрузку и документ условий использования
либо согласовать источник с применимой публичной лицензией. HTTP-блокировку решает
владелец источника. Ни IP/cookies обходы, ни предположение лицензии не применяются.
Для разработки большой сторонний классификатор не потребовался: есть собственное
дерево из 5055 узлов. Shopify taxonomy не загружалась и не встраивалась в архитектуру.

Команды воспроизведения, утверждения review, явного apply и отдельного SQL-отчёта:
[docs/import.md](../import.md). Матрица сценариев: [docs/test-matrix.md](../test-matrix.md).
