# Раздел для добавления в корневой README.md

Раздел перенесён в корневой README. Ниже сохранена исходная памятка форматов;
условия запуска и решение владельца об отключённой авторизации см. README.

## Импорт номенклатуры (этап 02)

После выполнения UI-дополнения откройте `http://<HOST>:<PORT>/admin/import` (реальный URL зависит от конфигурации), выберите файл или перетащите его в поле загрузки, проверьте распознанный формат и столбцы. Для однозначно распознанных файлов включён автозапуск после проверки; при нестандартной структуре настройте колонки и нажмите **«Начать обработку»**. Справа будут выводиться события идентификации и классификации; неразнесённые позиции можно назначить вручную через дерево категорий или создать категорию при наличии административных прав.

**Форматы:** JSON (`catalog_items_v1` или исходный AITIM archive); XML (`catalog_items_v1`); XLSX (таблица с заголовками в выбранной строке); CSV (UTF-8, `;`/`,`/tab, строка заголовков). Расширение `SVC` не используется; правильное расширение текстовой таблицы — `.csv`. `.xls`/`.xlsm` в этот этап не входят.

**Обязательное поле:** `name`. Необязательные: `source_key`, `brand`, `manufacturer`, `mpn`, `unit`, `quantity`, `price`, `currency`, `price_date`, `seller`, `seller_inn`, `product_url`, `category_path`. Пустые значения не заполняются догадками.

**Минимальный JSON:**

```json
{"schema_version":1,"source":"user_upload","items":[{"name":"Выключатель концевой XCKN2145P20","mpn":"XCKN2145P20"}]}
```

**Минимальный XML:**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<catalog schema_version="1" source="user_upload"><item><name>Выключатель концевой XCKN2145P20</name></item></catalog>
```

**Минимальный XLSX:** лист `Товары`, первая строка заголовков: `name | brand | mpn | unit | price`, далее по одному товару в строке.

**Минимальный CSV:**

```csv
name;brand;mpn;unit;price
"Выключатель концевой XCKN2145P20";;XCKN2145P20;;
```

Схемы и полные примеры: [docs/import-formats.md](import-formats.md), `docs/contracts/catalog_items_v1.schema.json`, `docs/contracts/catalog_items_v1.xsd`, файлы `examples/import_formats/`. Журнал показывает реальные обработанные позиции; сомнительные Product/категории не подтверждаются автоматически. Исторические цены не считаются текущими. При первом запуске пользователь должен иметь соответствующие права; параметры подключения к shared VLM/embedding задаёт администратор, не вводятся в форму.
