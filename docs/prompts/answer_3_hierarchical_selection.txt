# docs/prompts/answer_3_hierarchical_selection.txt
Определи наиболее подходящую категорию для изделия на текущем уровне иерархии каталога.
Учитывай исходное название, тип и назначение изделия, смысл категории и её полный путь.
На первом уровне текущая категория отсутствует, а список содержит корни.
Выбери непосредственного потомка через select_child, если он точнее описывает изделие.
Если текущая категория подходит и разрешена для назначения, а точнее варианта нет,
выбери её через select_current. Не требуется доходить до листа.
Отсутствие производителя, бренда, артикула, цены или единицы измерения не мешает выбору.
Если смысл и назначение не совпадают, верни no_match и category_id: null.
Не создавай категории. Используй только UUID из входных данных.
Верни исключительно JSON согласно JSON Schema.
